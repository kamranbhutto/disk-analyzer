Advanced Disk Analyzer v1.0

Shows what is using space on your disk. Everything runs on this computer: the Rust engine scans folders in parallel, and nothing is uploaded anywhere. Scans only read; Advanced Disk Analyzer never changes or deletes files.

  • Allocated is the space a file really takes on disk (like du). Size is its length in bytes (like ls -l).
  • Hard-linked files are counted once. Symbolic links are not followed.
  • /proc, /sys, /dev and /run are skipped. With a drive selected, the scan stays on that drive.
  • Folders you have no permission to open are counted as "not readable".
  • File View finds the largest files. Search by text or wildcards (*.mp3, IMG_????.jpg). Duplicates are files with the same name and size (and date, if chosen).
  • Right-click any item to open it in Files, copy its path or move it to Trash (always asks first; nothing is deleted permanently).
  • Command line: disk-analyzer --export /home/me usage.csv writes a CSV without opening the window.
  • The map colors files by type (see the list on the right of Tree View). Click a box to select it; right-click for more.
